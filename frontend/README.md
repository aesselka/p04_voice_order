# Voice Order - киоск (P04)

React + Vite. Экран киоска: меню карточками + голосовой заказ + корзина. Голос, текст и тапы по меню меняют **одну и ту же корзину** на бэке, поэтому их можно смешивать: сказать «два бургера», потом тапнуть «+», потом голосом «колу сделай большой».
Без бэка работает на встроенном mock-движке (`src/mock/engine.js`).

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173 (голос работает в Chrome/Edge, нужен доступ к микрофону).

Тест текстовых диалогов на mock-движке:

```bash
npm run test:dialogs
```

## Подключение к Python-бэку (voice_cart_nlu)

1. Запустить бэк: `py -m uvicorn voice_cart_nlu.api:app --reload` (порт 8000)
2. В папке фронта: `copy .env.example .env` (в нём `VITE_API_URL=http://127.0.0.1:8000`)
3. `npm run dev`, внизу сайдбара должна гореть зелёная точка **API**
4. Для прямых ручных действий примени [BACKEND_PATCH.md](BACKEND_PATCH.md) (один эндпоинт `/cart/{id}/actions`). Без него кнопки идут текстом.

Запросы `/cart/*` проксирует Vite, CORS в бэке менять не нужно. После правки `.env` перезапустить `npm run dev`.

Используемые эндпоинты бэка: `POST /cart/{id}/text`, `POST /cart/{id}/voice`, `POST /cart/{id}/actions`, `DELETE /cart/{id}`.
Адаптер ответа (тиыны -> тенге, `notes` + `question` -> текст ответа, `missing`/`pending` комбо) - в `src/api.js`.
Меню для левой колонки - копия `voice_cart_nlu/data/menu.json` в `src/backendMenu.json` (у Python-бэка нет /api/menu).

## Как голос и меню дружат

- Голос или текст: `/cart/{id}/text` (или `/voice`), бэк распознаёт намерение и меняет корзину.
- Тап по карточке, `+`/`-`, `✕`, выбор варианта комбо: `/cart/{id}/actions` с готовыми Action.
- Оба пути возвращают одну и ту же корзину, фронт просто перерисовывает её.
- Когда голос что-то добавил, карточка в меню подсвечивается, на ней счётчик штук в корзине.
- Если бэк задал уточнение (гарнир, размер комбо), под микрофоном появляются кнопки вариантов. Их можно нажать или сказать голосом.

## Режим киоска

- **Заставка** при старте и после 60 с простоя с пустой корзиной: «Закажите голосом», большая кнопка микрофона, выбор языка. Заказ в процессе заставка никогда не прячет.
- **Автосброс**: через 20 с после подтверждения заказа - новый заказ и заставка (отсчёт виден под кнопкой).
- **Микрофон всегда включён**: одно нажатие - слушает, пока не выключат; можно листать и тапать меню параллельно, всё идёт в очередь.
- **Тап по напитку/гарниру, пока комбо ждёт выбора** - засчитывается как ответ комбо.
- **Казахский**: названия блюд, добавок и вопросы про комбо переводятся на фронте (словари `KZ_ITEM`, `KZ_MOD` в `src/api.js`), т.к. в `menu.json` бэка только русские названия.
