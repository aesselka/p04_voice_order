## Запуск

```bash
uvicorn voice_cart_nlu.api:app --reload
```

- Киоск ML: http://127.0.0.1:8000/
- Админка: http://127.0.0.1:8000/admin
- Swagger: http://127.0.0.1:8000/docs

Переменные: `CART_DB` — файл SQLite (по умолчанию `carts.db`), `ADMIN_TOKEN` — если задан, админка требует заголовок `X-Admin-Token`.

## API

| Метод | URL | Что делает |
|---|---|---|
| GET | `/menu` | меню с учётом стоп-листа (`available`) |
| POST | `/cart` | новая корзина → `{"cart_id": "<uuid>"}` |
| POST | `/cart/{id}/text` | фраза → корзина |
| POST | `/cart/{id}/voice` | аудио → корзина |
| POST | `/cart/{id}/actions` | кнопки киоска: `{"actions": [Action, ...]}` |
| GET / DELETE | `/cart/{id}` | показать / сбросить корзину |
| GET / PUT | `/admin/upsell` | правила допродажи |
| GET / PUT | `/admin/stop-list` | `{"item_ids": ["cinnabon"]}` — чего нет в наличии |

`id` корзины — от 16 символов (`crypto.randomUUID()` подходит).

### Upsell в ответе

Каждый ответ корзины может содержать поле `upsell`:

```json
"upsell": {"item_id": "fries", "name": "Картофель фри", "name_kk": "Фри картобы",
           "price_cents": 65000, "text": "Добавить картофель фри к бургеру?"}
```

- Предлагаем после добавления блюда, только когда нет вопроса про комбо. Одно блюдо — один раз за заказ, всего не больше 2 предложений.
- Гость говорит «да» → блюдо добавляется (заказ при этом **не** подтверждается). «Нет» → ничего не меняется.
- Кнопка «Добавить» во фронте: `{"type": "add_item", "item_id": upsell.item_id}` в `/actions`.

Правило: `{"trigger": "burger", "offer": "fries", "text": "..."}`. `trigger` — id блюда или категория
(`burger`, `combo`, `side`, `sauce`, `drink`, `dessert`). Проверяются сверху вниз.

## Допущения меню

На im.kz у каждой позиции одна цена: это размер M. Цены S/L (фри и газировка), платные добавки (сыр, халапеньо, сироп)
и состав комбо (напиток + гарнир на выбор, по-деревенски +300 ₸) придумали мы. Это указано в `_note` в `menu.json`.

## Тесты

```bash
python -m pytest
```

Тесты и eval работают на фиксированном тестовом меню `tests/data/menu_test.json` (старое меню на 16 позиций),
поэтому ожидаемые цены не ломаются при смене настоящего меню. Новые тесты бэкенда — `tests/test_backend.py`,
они проверяют меню I'M, наличие, upsell, SQLite и API. Метрики eval остались прежними: корзина 88.6%, правки 92.9%,
0 ошибок цены.

## Передать команде

**ML (NLU):**
- B3 не исправлен: «бургер без лука **и с сыром**» убирает и сыр.
- «картошку по-деревенски» распознаётся как две позиции (фри + по-деревенски): предлог «по» разрывает название.
